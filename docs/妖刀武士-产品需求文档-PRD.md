# 《妖刀武士》产品需求文档（PRD）

> **文档版本：** 1.0  
> **文档状态：** MVP 产品定义稿  
> **游戏类型：** 单人、PvE、2D 俯视角经营 + 动作战斗 RPG  
> **目标平台：** PC 浏览器  
> **核心操作：** 方向键移动，鼠标攻击与交互，Q/W/E/R 释放技能  
> **美术方向：** 风格化日式黑暗奇幻（Stylized Japanese Dark Fantasy）  
> **游戏名称：**《妖刀武士》

---

## 0. 文档说明

### 0.1 文档目的

本文定义《妖刀武士》的产品定位、世界观、角色、战斗、技能、装备、妖魂、等级成长、怪物、地图关卡、界面交互和 MVP 验收标准，作为游戏内容设计与后续制作验收的统一依据。

本文描述玩家体验、玩法规则与内容要求，并明确首版技术方向：使用 **Phaser** 作为 2D 游戏引擎，角色与怪物动作使用 **Sprite Sheet（精灵图集）** 实现。具体代码架构和数据结构可在开发阶段另行定义。

#### 0.1.1 技术与表现方向

| 项目 | 方案 |
|---|---|
| 游戏引擎 | Phaser |
| 游戏渲染 | Phaser 2D Canvas / WebGL 渲染能力，按目标浏览器验证 |
| 场景组织 | 据点场景、战斗场景、UI 场景分层管理 |
| 地图碰撞 | Tilemap 碰撞层 + 独立实体碰撞体 |
| 动画播放 | Phaser Animation 系统读取 Sprite Sheet 帧配置 |
| 游戏形态 | 2D 浏览器游戏 |
| 视角 | 正交俯视角（Top-down），不使用 3D 模型或 3D 斜视镜头 |
| 地图 | Tilemap / 2D 场景图块，搭配独立场景装饰 |
| 角色与怪物动画 | Sprite Sheet 精灵图集，按动作拆分动画帧 |
| 特效 | 2D 序列帧、粒子效果、程序化简易特效 |
| UI | 2D HUD 与面板 UI，与游戏场景分层 |
| 目标平台 | PC 浏览器优先，采用键鼠操作 |

### 0.2 设计原则

1. **小而完整：** 首个版本必须有完整的“据点经营—出征—战斗—收集—成长—返回据点—升级经营设施”闭环，不以地图数量或内容堆积衡量完成度。
2. **操作简单，选择有深度：** 玩家只需要普通攻击、移动和 Q/W/E/R 四个主动技能；策略深度主要来自技能时机、装备词缀和妖魂组合。
3. **战斗反馈清晰：** 敌我攻击范围、受击、技能命中、危险预警和掉落品质都必须容易辨认。
4. **成长可感知：** 升级、装备替换和妖魂效果应让玩家明显感受到角色变化，而不是只增加难以感知的数字。
5. **经营与战斗相互驱动：** 据点设施提供补给、装备、成长和出征准备；战斗产出的资源反过来推动据点发展。经营不能成为与战斗割裂的独立小游戏。
6. **内容范围可控：** MVP 使用一个据点、一张主要战斗地图、固定主角和有限怪物种类，不加入多人、职业选择、复杂制作或开放世界系统。
7. **先验证乐趣，再扩充内容：** 所有数值均为首轮测试基准，需通过实际试玩调整，不视为已经验证的最终平衡值。

### 0.3 名词定义

| 名词 | 定义 |
|---|---|
| 武士 | 玩家操控的主角，一名失去主君与家族、持有妖刀的武士 |
| 妖魂 | 妖怪被击败后遗留的力量结晶，可装备并改变角色属性或技能效果 |
| 封印楔 | 用于稳定黄泉封印的古老灵性器物；MVP 的核心任务物品 |
| 普通怪 | 构成关卡主要战斗密度的基础敌人 |
| 精英怪 | 比普通怪更强，具有强化属性或特殊机制的敌人 |
| 首领 / Boss | 关卡最终挑战对象，拥有独立攻击模式和阶段变化 |
| Build | 由装备、妖魂和技能强化构成的角色战斗配置 |
| 据点 | 玩家返回后进行补给、设施升级、装备整理和出征准备的经营区域 |
| 经营资源 | 用于据点设施升级与服务的木材、铁矿、金币等资源 |
| Sprite Sheet | 将角色或怪物多个动画帧排列在一张图片中的精灵图集 |
| MVP | 首个可独立体验并用于验证核心玩法的最小完整版本 |

### 0.4 本文数值口径

本文中的生命值、伤害、经验、冷却时间、掉落概率和战斗时长均为**原型初始建议值**。它们用于形成可测试的规则，不代表经过用户测试或商业化验证的平衡结论。首轮试玩后应根据通关率、战斗时长、技能使用频率、掉落感受和玩家反馈调整。

# 1. 产品概述

## 1.1 一句话定义

《妖刀武士》是一款以日本战国妖怪传说为背景的 2D 俯视角经营与动作战斗 RPG。玩家扮演一名持有妖刀的流浪武士，以一处破败道场为据点，通过修缮设施、管理资源、准备补给和招募协助者发展据点；随后进入俯视角战斗地图，使用移动、普通攻击和四个主动技能斩杀妖怪，收集装备与妖魂，逐步成长并揭开黄泉异变的真相。

## 1.2 核心体验

玩家围绕据点与战斗地图展开持续循环，单次出征约 8–15 分钟：

**据点经营与整备 → 选择出征区域 → 探索地图 → 遭遇怪物并战斗 → 获得经验、装备和经营资源 → 击败精英 / Boss → 返回据点 → 升级设施、补充物资并调整 Build。**

玩家应该持续获得三类反馈：

- **即时反馈：** 斩击命中、敌人受击、技能释放、闪避成功、敌人被击败。
- **阶段反馈：** 经验升级、装备品质提升、妖魂获取、技能强化。
- **目标反馈：** 解锁神社深处、击败首领、净化封印、发现新的故事线索。

## 1.3 产品定位与边界

| 维度 | 定位 |
|---|---|
| 游戏类型 | 单人 PvE 俯视角经营 + 动作战斗 RPG |
| 视角 | 2D 正交俯视角（Top-down），镜头跟随玩家 |
| 移动 | 方向键连续移动，鼠标不负责角色移动 |
| 普通攻击 | 鼠标左键或指定攻击键进行基础攻击；不自动寻路接近敌人 |
| 主动技能 | Q、W、E、R 四个技能 |
| 角色 | 固定一名武士，不提供职业和角色创建 |
| 成长 | 角色等级、技能强化、装备、妖魂、据点设施等级 |
| 场景 | 1 个可经营据点 + 固定结构的区域式战斗地图与地下神社副本 |
| 目标时长 | 首次完整体验 10–15 分钟；重复挑战时长允许浮动 |
| 目标用户 | 喜欢日式武士、妖怪题材、轻量刷怪、装备收集和短局 PvE 的玩家 |

### 1.4 MVP 不包含的内容

以下内容明确不属于首个版本的交付范围：

- 多人联机、PVP、公会、交易和排行榜竞争。
- 多职业、多个可选主角、角色捏脸或复杂外观编辑。
- 大型无缝开放世界、随机生成地图或大规模剧情分支。
- 多据点经营、复杂 NPC 日程、村民生存模拟和大规模生产链。
- 坐骑、宠物、钓鱼等外围系统。
- 复杂连招、格挡架势、弹反判定、体力管理和多种能量条。
- 妖魂合成、升星、进化、套装羁绊等深度养成系统。
- 装备强化、洗练、镶嵌宝石、交易行等额外经济系统。
- 移动端触屏操作适配（首版不作为验收要求）。
- 付费商城、抽卡、广告激励和商业化系统。

# 2. 故事背景与世界观

## 2.1 故事基调

故事发生在一个架空的日本战国时代。整体基调是**苍凉、神秘、克制的黑暗奇幻**，而非纯恐怖题材。世界中既有人类战争造成的苦难，也有妖怪传说带来的超自然威胁。

故事关注的核心主题：

- 忠诚与背叛：当主君不再值得效忠，武士还剩下什么？
- 执念与救赎：仇恨能给予力量，也会吞噬持有者。
- 人与妖：妖怪并非全都邪恶，人类也并非天然正义。
- 选择与代价：力量可以解决眼前的危机，却可能带来更大的代价。

## 2.2 世界历史

很久以前，人间与黄泉之间存在一道被称为“黄泉之界”的边界。亡者归于黄泉，生者留在人间，少数神社、古寺和山中禁地承担着维系边界的职责。

数百年前，传说中的阴阳师与山中修行者共同建立了七处封印节点，并以七枚“封印楔”稳定黄泉之界。封印并未消灭黄泉，只是让生与死各归其位。

战国乱世持续多年。战争、饥荒、屠城和背叛积累了大量强烈的怨念。二十年前，一场被称为“赤月之灾”的异变发生：月亮在一夜之间染成暗红色，多处封印节点受损，亡魂无法安然归于黄泉，妖怪开始频繁现身。

大多数百姓只知道夜晚变得危险。各地大名却逐渐得知，黄泉之力可以被利用。有人希望借妖魔之力赢得战争，有人寻求长生，也有人只想让死去的亲人回来。

人间因此陷入第二场灾难：妖怪横行，诸侯争夺禁术，曾经守护封印的家族也被卷入权力斗争。

## 2.3 主角背景

玩家扮演的主角是一名没有姓名记载的武士。玩家可在开局为其选择一个称呼，但不改变剧情和战斗能力。游戏叙事中统一称其为“武士”。

主角曾效忠于月影家，是一名擅长快速拔刀与近身战斗的年轻武士。十年前，月影城遭到袭击并在一夜之间覆灭。主角在城破之夜身受重伤，醒来时已被逐出家族旧地，并被外界指认为临阵脱逃的叛徒。

他被一名隐居山中的老剑客救下。老剑客没有向他解释当夜真相，只教他如何活下去，并反复告诫：“刀可以斩断敌人的性命，却斩不断一个人的执念。”

数年后，老剑客失踪。主角带着祖传太刀“残月”独自流浪，靠护送商旅、清剿山贼和猎杀妖怪谋生。

某日，他经过枫隐村，发现村中居民失踪，夜里有鬼火从废弃神社升起。神社石碑上出现了只有月影家才懂的封印纹样。武士由此开始追查十年前的灭门真相。

## 2.4 妖刀·残月设定

“残月”是一把传承于月影家的妖刀太刀。刀身并非持续发光的魔兵，平时外观朴素，只有接近妖怪或封印时，刃口才会出现暗红色纹路。

残月具有两种属性：

1. **斩妖：** 能够伤害普通刀剑难以伤害的怨灵和妖物。
2. **共鸣：** 吸收被击败妖怪残留的力量，使持有者能够使用妖魂。

残月并不是黄泉之门的钥匙，也不能凭一己之力打开或关闭黄泉。它是月影家守护封印的媒介，能够感知封印状态、承载妖魂，并短暂压制妖气。

它的力量并非没有代价。若持有者不断吸收妖魂、沉溺于仇恨，刀身会逐渐被侵蚀。MVP 不呈现复杂的堕落数值系统，只通过剧情演出和视觉反馈暗示风险。

## 2.5 主线悬念

主角最初认为月影家遭到灭门，是某位大名为了夺取封印楔而发动的袭击。随着探索深入，他发现当夜真正的目标不是城池，而是月影家守护的封印节点。

武士的师父曾参与封印行动，也曾与月影家发生冲突。师父当年隐瞒真相，是因为月影家内部有人试图利用残月吸收黄泉之力。为阻止灾难，师父带走了部分封印记录，并在城破后救走了武士。

MVP 不揭晓全部真相，只提供三个线索：

- 枫隐村的封印纹样与残月产生共鸣。
- 神社壁画描绘了七处封印节点，其中一处已经破损。
- Boss 战后获得的残缺记录提到“月影家并非唯一守门人”。

这样，首个版本可以形成独立故事闭环，同时留下继续扩展的空间。

## 2.6 MVP 故事闭环

枫隐村的封印节点被一只强大的怨鬼侵蚀。村民失踪并非全部死亡，其中一些人被困在神社地下的结界中。主角追踪鬼火进入神社，击败守护封印的“赤月鬼将”，取得第一枚封印楔，并利用妖刀暂时稳定节点。

关卡结束时，封印并未永久修复。主角从神社记录中得知，其他封印节点也出现异常。故事以主角离开枫隐村、继续寻找其余节点作为结尾。

**MVP 的剧情结果：** 枫隐村的危机解除，部分村民获救，主角得到第一条可信线索，但十年前的灭门真相仍未完全揭开。

# 3. 角色设计

## 3.1 玩家角色：武士

| 项目 | 设计要求 |
|---|---|
| 身份 | 月影家旧部，现为无主武士 |
| 年龄感 | 成年男性，约二十多岁至三十岁之间；不以年龄作为玩法属性 |
| 外观 | 深色旧和服、轻型护肩、腰间太刀、旅行斗笠可作为外观元素 |
| 体态 | 精干、敏捷，不采用夸张重甲或巨大武器 |
| 性格 | 寡言、谨慎、克制；对弱者仍保留保护欲 |
| 核心动机 | 查明月影家覆灭的真相，阻止黄泉异变扩大 |
| 核心武器 | 太刀“妖刀” |
| 战斗定位 | 近战、机动、范围清怪与短时间爆发 |

### 3.2 角色表现要求

- 主角的普通攻击和技能应体现刀剑动作，不依赖拳脚或大型魔法。
- 技能视觉可以带有残影、风压、鬼火和妖气，但主角始终以太刀为主要战斗手段。
- 受击、低生命值、升级、拾取传奇装备和获得妖魂时应有明确反馈。
- 主角在非战斗状态不应持续做夸张动作；整体表现应沉稳、警觉。
- 剧情对话保持简洁，避免大量长篇对白打断刷怪节奏。

### 3.3 角色成长定位

玩家不选择职业。所有玩家拥有相同的基础技能和装备槽位，战斗风格通过以下方式形成：

1. 技能强化方向；
2. 装备主属性与词缀；
3. 三个妖魂槽位的组合。

这样可以控制角色内容成本，并让玩家把注意力放在 Build 变化上。

### 3.4 NPC（MVP）

MVP 不要求建立大型城镇或常驻 NPC 系统，只设置两类叙事角色：

| 角色 | 作用 | MVP 出现方式 |
|---|---|---|
| 失踪的神社巫女 | 引导玩家了解封印与村庄异变；是获救村民的代表 | 通过关卡中的短场景、纸条和结尾对话出现 |
| 老剑客（师父） | 与主角过去及封印真相有关 | 只通过回忆片段、信件或声音线索出现，不参与战斗 |

# 4. 核心玩法与规则

## 4.1 核心循环

1. 玩家进入枫隐村关卡。
2. 使用 方向键在 2D 俯视地图中移动，探索道路、村落和神社入口。
3. 遭遇妖怪，使用普通攻击键攻击敌人，使用 Q/W/E/R 技能应对不同战况。
4. 击败敌人获得经验、金币以及概率掉落的装备或妖魂。
5. 玩家拾取掉落物，决定装备、更换或保留物品。
6. 通过等级提升和装备调整增强角色。
7. 击败精英怪、收集任务线索并进入地下神社。
8. 击败 Boss，取得封印楔并完成关卡。

## 4.2 据点经营系统

### 4.2.1 系统定位

据点是玩家每次出征前后的主要活动空间，也是经营玩法的核心。MVP 将据点设定为枫隐村边缘的一处废弃道场。玩家在解决村庄危机后逐步修复道场，将其发展为武士与村民暂时避难、整备和交易的场所。

经营系统以“资源投入—设施升级—功能解锁—出征效率提升”为主，不做复杂的模拟经营数值和 NPC 日程系统。

### 4.2.2 据点核心设施

| 设施 | 初始状态 | 主要功能 | 升级收益 |
|---|---|---|---|
| 道场主屋 | 初始开放 | 据点主界面、存档与任务入口 | 解锁其他设施等级上限 |
| 刀匠铺 | 初始损坏 | 查看、整理和更换装备 | 解锁更高阶装备购买 / 打造选项（MVP 可简化为固定兑换） |
| 物资屋 | 初始损坏 | 购买伤药、补给和出征物资 | 增加补给种类或库存 |
| 神龛 | 初始开放 | 妖魂装备、图鉴和净化 | 解锁妖魂槽位或提供少量常驻加成 |
| 训练场 | 初始损坏 | 查看技能、分配技能点 | 提供训练奖励或技能强化便利 |

MVP 不要求自由摆放建筑。设施采用固定位置和固定交互点，玩家靠近后按 F 打开对应面板。

### 4.2.3 经营资源

| 资源 | 主要来源 | 用途 |
|---|---|---|
| 金币 | 怪物掉落、任务奖励、出售装备 | 购买补给、设施升级 |
| 木材 | 战斗地图中的资源箱、任务奖励 | 修复道场与物资屋 |
| 铁矿 | 战斗地图中的矿石点、精英奖励 | 升级刀匠铺、训练场 |
| 妖魂碎片 | 精英怪、Boss、特殊事件 | 神龛升级或兑换指定妖魂 |

资源不设置复杂的生产链。首版资源以战斗探索获取为主，避免玩家必须等待现实时间或反复点击生产。

### 4.2.4 设施升级规则

- 每个可升级设施建议设置 2–3 个等级。
- 升级需要消耗指定资源，确认后立即完成，不设置现实时间等待。
- 升级前展示资源需求、升级结果和当前资源数量。
- 资源不足时明确显示缺少项，不允许负数扣除。
- MVP 只开放少量关键升级，确保玩家至少完成一次设施修复和一次设施升级。
- 设施升级应提供可感知收益，不能只改变建筑外观或等级数字。

### 4.2.5 据点 NPC

MVP 仅保留功能型 NPC，不设计复杂日程和好感度：
- 刀匠：装备整理、固定装备兑换或基础装备服务。
- 商人：购买伤药和基础补给。
- 巫女：妖魂相关服务、剧情提示和神龛净化。
- 村民：通过简短对话提供任务或资源奖励。

NPC 可使用静态立绘 / Sprite 和少量待机动画。对话采用短文本，不要求全程配音。

### 4.2.6 据点与战斗的关联

- 玩家从据点选择已开放区域出征。
- 出征前可更换装备、配置妖魂、购买补给和查看区域推荐等级。
- 战斗获得的金币、木材、铁矿和妖魂碎片带回据点。
- 设施等级影响补给、装备服务或角色成长便利性。
- 玩家失败后保留已获得的角色经验和已拾取物品；本次未拾取的地面掉落不保留。
- MVP 不设置资源被袭击、建筑损毁或离线经营损失。

## 4.3 战斗基本规则

- 玩家生命值降至 0 时视为倒下，当前关卡挑战失败。
- MVP 采用单人 PvE，不存在队友复活、仇恨分摊或玩家间伤害。
- 玩家可以在非战斗状态自然恢复少量生命值；进入战斗后停止自然恢复。建议初始规则为脱离战斗 5 秒后，每秒恢复最大生命值的 2%。
- 普通攻击没有资源消耗，攻击速度由角色属性和装备决定。
- 主动技能使用固定冷却，不消耗法力或怒气。
- 技能冷却在角色倒下或关卡结算后重置。
- 角色受到攻击时应有短暂受击反馈，但 MVP 不设计复杂的硬直、韧性和霸体数值体系。

## 4.4 战斗节奏

- 普通怪：玩家应能通过普攻与一到两个技能快速处理。
- 多只普通怪：鼓励玩家利用 W 范围技能和走位聚怪。
- 精英怪：需要观察攻击预警并合理使用 E 闪避。
- Boss：需要识别攻击范围、在安全窗口输出，并在危险攻击前移动离开。

建议普通怪单只战斗时间约 3–8 秒，精英怪约 15–30 秒，首领战约 1.5–3 分钟。以上为试玩目标区间，不是强制硬性时间。

## 4.5 失败与重试

- 玩家倒下后，显示失败界面。
- 玩家可以选择重新挑战或返回标题界面。
- MVP 不采用经验扣除、装备损坏或永久丢失装备等惩罚。
- 关卡内尚未拾取的掉落物在失败后消失；已进入背包的物品保留。
- 重试时关卡内普通怪、精英怪、机关和首领恢复初始状态。
- 已完成的关卡进度以“关卡完成”为单位保存；MVP 不提供关卡内检查点。

# 5. 操作与交互设计

## 5.1 输入规则

| 输入 | 行为 | 说明 |
|---|---|---|
| 方向键 | 移动 | 角色按输入方向连续移动 |
| 鼠标左键 / 攻击键 | 普通攻击 | 对当前面向方向或锁定目标发动攻击 |
| 鼠标点击精英 / Boss | 目标锁定 | 锁定目标并显示血条，不自动移动 |
| F | 交互 / 拾取 | 靠近设施、NPC、宝箱或掉落物后交互 |
| Q | 居合斩 | 沿角色当前面向方向释放突进斩击 |
| W | 旋风斩 | 以角色为中心释放圆形范围攻击 |
| E | 影步 | 朝当前移动方向短距离闪避；无方向输入时朝角色面向闪避 |
| R | 鬼神斩 | 朝角色当前面向方向释放大范围斩击 |
| I | 背包 | 打开 / 关闭背包面板 |
| C | 角色 | 打开 / 关闭角色属性与装备面板 |
| B | 据点 / 建造 | 在据点打开经营与设施管理界面 |
| K | 技能 | 打开 / 关闭技能强化面板 |
| F | 交互 / 拾取 | 与 NPC、设施、宝箱和掉落物交互 |
| Esc | 暂停 | 打开暂停菜单；暂停期间世界战斗停止 |
| 鼠标悬停 / 靠近交互物 | 查看提示 | 显示敌人、物品或交互点的简要信息 |

**输入优先级：** 当背包、角色面板、暂停菜单等模态界面打开时，游戏世界不接收普通移动和攻击输入；技能快捷键不应误触发。关闭面板后恢复游戏操作。

## 5.2 移动交互

- 按下 方向键，角色按对应方向连续移动；松开按键后停止。
- 角色碰到墙体、建筑和地图边界时应被碰撞阻挡，不得穿墙或卡入障碍物。
- 玩家可随时改变方向；角色移动方向应及时响应输入，斜向移动速度需归一化。
- 玩家需主动移动接近敌人并进入攻击范围；不采用点击敌人后自动寻路追击。
- 若目标死亡或离开攻击范围，角色停止对该目标的连续攻击。
- 角色移动与待机动画切换应自然，停止输入后及时进入待机状态。
- 移动方向由键盘输入决定，地面不显示点击目的地标记。

## 5.3 目标选择与攻击

- 被选中的敌人应有明确选中标识。
- 敌人名称、等级和生命条只在悬停、选中或进入战斗时显示，避免画面长期充满 UI。
- 普通攻击由鼠标左键或设定的攻击键触发；按住攻击键可连续攻击当前朝向或最近有效目标。
- 玩家可通过鼠标点击敌人进行目标锁定；锁定只辅助攻击，不触发自动寻路。
- 若目标距离过远，攻击不应自动触发位移；玩家需自行移动接近目标。
- 攻击动作、命中效果和伤害数字应与实际伤害结算一致，不允许出现明显“刀已命中但敌人无反馈”的情况。

## 5.4 技能释放交互

- 技能栏始终显示 Q/W/E/R 对应图标、冷却状态和可用状态。
- 技能可用时图标清晰；冷却中显示剩余时间或冷却遮罩。
- 技能释放成功后有明确动作、音效和效果反馈。
- 技能不可用时，不执行动作，并通过图标或轻提示说明原因（冷却中、角色倒下、关卡结算等）。
- 需要方向的技能优先沿角色当前面向方向释放；玩家可通过移动方向调整角色面向；鼠标点击敌人仅用于目标锁定。
- 技能释放期间不应意外触发鼠标键盘移动。

## 5.5 物品拾取与装备交互

- 掉落物出现在地面，并使用品质颜色、轮廓或光效体现稀有度。
- 普通金币和经验在敌人死亡时自动获得；若以地面掉落表现，也应在玩家靠近时自动吸收。
- 装备与妖魂需玩家靠近后按 F 或点击交互提示拾取。
- 拾取装备后进入背包，不自动替换当前装备。
- 玩家可以在背包中查看装备属性、与当前装备对比并确认穿戴。
- 背包满时不丢弃已有物品，提示玩家清理空间后再拾取。

## 5.6 暂停与结算

暂停菜单至少提供：继续游戏、重新挑战、返回标题界面。暂停期间怪物停止移动和攻击，技能冷却及关卡计时停止。

关卡结算界面至少显示：是否完成、通关用时、角色等级、击败怪物数量、获得装备、获得妖魂、任务结果和继续 / 重玩选项。

# 6. 战斗技能设计

## 6.1 技能设计原则

- 仅有四个主动技能，技能之间必须有清晰分工。
- 普攻负责稳定输出；Q 负责突进和单体打击；W 负责近身清怪；E 负责脱离危险；R 负责高爆发范围伤害。
- 技能不使用蓝量或怒气，避免增加额外资源管理负担。
- 技能效果以刀剑动作、风压、残影和妖气为主，不让主角变成远程法师。
- 技能数值必须给普通怪、精英怪和 Boss 留出差异化体验。

## 6.2 普通攻击

| 项目 | 规则 |
|---|---|
| 名称 | 武士刀术 |
| 输入 | 鼠标左键 / 攻击键按住后连续攻击当前面向方向或锁定目标 |
| 目标 | 单体近战敌人 |
| 初始攻击距离 | 约 1.8 个游戏距离单位 |
| 初始攻击间隔 | 约 0.9 秒 |
| 基础伤害 | 100% 攻击力 |
| 特性 | 无冷却、无资源消耗，是稳定输出来源 |

普通攻击可使用 2–3 个连续斩击动作循环，但不设计需要玩家输入的连招判定。攻击速度属性只缩短攻击间隔，不改变技能冷却。

## 6.3 Q 技能：居合斩

| 项目 | 设计 |
|---|---|
| 定位 | 方向突进、单体爆发、接近敌人 |
| 输入 | Q |
| 冷却 | 5 秒（初始值） |
| 距离 | 最多约 4 个距离单位 |
| 伤害 | 200% 攻击力（初始值） |
| 目标 | 路径或终点附近的敌人；优先突出主要目标命中反馈 |
| 表现 | 短暂收刀、瞬间拔刀、刀光残影 |
| 限制 | 不能穿越不可通行的实体障碍；被控制或倒下时不能释放 |

**技能说明：** 主角朝当前面向方向高速突进，拔刀斩击沿途敌人。技能重点是快速接近和单体爆发，而非长距离穿越地图。

**强化方向：**

- 强化 A：伤害提高，适合单体输出。
- 强化 B：命中敌人后短暂提高移动速度，适合追击。

## 6.4 W 技能：旋风斩

| 项目 | 设计 |
|---|---|
| 定位 | 近身范围伤害、清理小怪 |
| 输入 | W |
| 冷却 | 8 秒（初始值） |
| 范围 | 角色周围半径约 3 个距离单位 |
| 伤害 | 120% 攻击力（初始值） |
| 目标 | 范围内所有敌人 |
| 表现 | 角色旋身横斩，形成清晰的环形刀风 |
| 限制 | 释放时角色短暂定身；不提供无敌效果 |

**技能说明：** 主角旋身挥刀，对周围敌人造成范围伤害。该技能用于处理围攻，不应同时承担位移或防御功能。

**强化方向：**

- 强化 A：范围扩大约 20%。
- 强化 B：命中至少 3 名敌人时，返还少量技能冷却（建议 1 秒）。

## 6.5 E 技能：影步

| 项目 | 设计 |
|---|---|
| 定位 | 位移、躲避危险攻击、调整站位 |
| 输入 | E |
| 冷却 | 6 秒（初始值） |
| 距离 | 最多约 5 个距离单位 |
| 伤害 | 不造成伤害 |
| 表现 | 短距离闪身并留下暗色残影 |
| 防御效果 | 位移期间具有极短的规避判定；不应覆盖整个技能冷却时间 |
| 限制 | 不能穿过地图边界或不可通行障碍；不能连续无代价逃离所有 Boss 攻击 |

**技能说明：** 主角朝当前面向方向快速闪避。此技能不负责输出，核心价值是让玩家有机会躲开 Boss 的范围攻击。

**强化方向：**

- 强化 A：冷却时间减少约 1 秒。
- 强化 B：闪避结束后短暂提高移动速度。

## 6.6 R 技能：鬼神斩

| 项目 | 设计 |
|---|---|
| 定位 | 高爆发范围技能、精英和 Boss 战的关键输出 |
| 输入 | R |
| 冷却 | 30 秒（初始值） |
| 范围 | 角色前方扇形区域，距离约 5 个单位 |
| 伤害 | 500% 攻击力（初始值） |
| 目标 | 扇形范围内所有敌人 |
| 表现 | 短暂蓄力后挥出巨大暗红色刀光，地面留下裂纹或残光 |
| 限制 | 蓄力期间可被打断；释放前有明显前摇，不应成为无风险瞬发技能 |

**技能说明：** 主角借助妖刀中封存的妖气，向前方释放强力斩击。技能伤害高、冷却长，适合在精英怪或 Boss 的输出窗口使用。

**强化方向：**

- 强化 A：伤害提高约 20%。
- 强化 B：击败普通怪物时返还部分冷却（建议每次触发最多返还 2 秒；Boss 不触发）。

## 6.7 技能强化规则

- 角色达到指定等级后获得技能点。
- MVP 每次升级获得 1 点技能点；首轮体验预计可获得 9 点左右，具体由经验曲线决定。
- 每个主动技能最多强化 2 次，每次强化从两个方向中选择一个。
- 同一技能的两个强化方向互斥，玩家不能同时获得两种强化。
- MVP 不提供重置技能点功能；若试玩中发现选择成本过高，可增加一次免费重置。
- 技能强化只改变既有技能，不增加新的主动技能按钮。

### 6.8 技能初始参数汇总

| 技能 | 冷却 | 基础效果 | 初始数值 |
|---|---:|---|---:|
| 普攻 | 无 | 单体近战伤害 | 100% ATK |
| Q 居合斩 | 5 秒 | 突进斩击 | 200% ATK |
| W 旋风斩 | 8 秒 | 周围范围伤害 | 120% ATK |
| E 影步 | 6 秒 | 短距离规避位移 | 无伤害 |
| R 鬼神斩 | 30 秒 | 前方大范围斩击 | 500% ATK |

# 7. 角色等级与成长设计

## 7.1 等级范围

- MVP 角色等级上限：10 级。
- 进入关卡时角色从 1 级开始，后续可根据关卡重玩规则决定是否保留成长；MVP 推荐将角色成长作为跨关卡存档保留，但单个 MVP 关卡只提供一次核心体验。
- 经验由击败怪物和完成关卡目标获得。
- 升级时立即恢复 20% 最大生命值，作为正向反馈，但不完全回复生命。
- 升级时自动提升基础属性并获得 1 个技能点。

## 7.2 基础属性

| 属性 | 初始值建议 | 作用 |
|---|---:|---|
| 最大生命值 HP | 500 | 生命值归零则倒下 |
| 攻击力 ATK | 50 | 决定普通攻击和技能伤害 |
| 防御 DEF | 10 | 减少受到的伤害 |
| 暴击率 | 5% | 攻击造成暴击的概率 |
| 暴击伤害 | 150% | 暴击时伤害倍率 |
| 攻击速度 | 1.0 | 普通攻击频率基准 |
| 移动速度 | 1.0 | 角色移动速度基准 |
| 技能冷却缩减 | 0% | 缩短主动技能冷却，设定上限 |

属性说明：以上为角色 1 级、未穿戴装备、未装备妖魂时的测试基准。初始数值应配合敌人生命值进行整体校准。

## 7.3 升级属性成长

建议每升一级：

- 最大生命值 +40；
- 攻击力 +5；
- 防御力 +1；
- 获得 1 个技能点。

等级成长表：

| 等级 | 累计经验建议 | 累计基础生命值 | 累计基础攻击力 | 累计基础防御 | 累计技能点 |
|---:|---:|---:|---:|---:|---:|
| 1 | 0 | 500 | 50 | 10 | 0 |
| 2 | 100 | 540 | 55 | 11 | 1 |
| 3 | 250 | 580 | 60 | 12 | 2 |
| 4 | 450 | 620 | 65 | 13 | 3 |
| 5 | 700 | 660 | 70 | 14 | 4 |
| 6 | 1,000 | 700 | 75 | 15 | 5 |
| 7 | 1,350 | 740 | 80 | 16 | 6 |
| 8 | 1,750 | 780 | 85 | 17 | 7 |
| 9 | 2,200 | 820 | 90 | 18 | 8 |
| 10 | 2,700 | 860 | 95 | 19 | 9 |

经验曲线用于让玩家在首轮关卡中达到约 6–8 级；若玩家清理全部区域、击败精英并完成探索，可接近更高等级。MVP 不要求所有玩家必然达到 10 级。

## 7.4 经验来源建议

| 来源 | 经验建议 |
|---|---:|
| 赤鬼 | 20 |
| 骸骨武士 | 25 |
| 怨灵 | 25 |
| 精英鬼将 | 100 |
| Boss 赤月鬼将 | 250 |
| 完成关卡主要目标 | 150 |
| 发现隐藏区域 | 50（每处一次） |

经验只在击败敌人或达成目标时发放，不允许通过重复触发同一机关无限刷取。

## 7.5 技能点与等级反馈

- 升级时显示明显提示，短暂暂停或降低战斗干扰，让玩家注意到成长反馈。
- 技能栏中可强化技能显示可用提示。
- 未分配技能点时，玩家可以继续战斗，不强制立即打开技能面板。
- 技能点可在关卡内分配；分配后立即生效。

# 8. 装备系统设计

## 8.1 装备目标

装备是玩家反复挑战关卡的主要追求之一。装备应提供易懂的属性提升，少量特殊词缀用于改变玩法。MVP 不追求海量随机词缀，优先确保每件装备的价值容易理解。

## 8.2 装备部位

角色拥有 6 个装备部位：

| 部位 | 主要属性 | 次要属性可能性 |
|---|---|---|
| 武器 | 攻击力 | 暴击率、技能伤害 |
| 头盔 | 生命值、防御 | 暴击率、生命恢复 |
| 铠甲 | 生命值、防御 | 受到伤害降低 |
| 护手 | 攻击速度、攻击力 | 暴击率、普通攻击伤害 |
| 战靴 | 移动速度 | 生命值、影步冷却 |
| 饰品 | 暴击率、冷却缩减 | 妖魂效果、技能伤害 |

每个部位同一时间只能穿戴一件装备。装备更换后，属性立即更新。

## 8.3 装备品质

| 品质 | 颜色建议 | 规则 | MVP 数量目标 |
|---|---|---|---:|
| 普通 | 白色 | 仅有基础属性 | 6 件 |
| 魔法 | 蓝色 | 基础属性 + 1 条附加属性 | 6 件 |
| 稀有 | 黄色 | 基础属性 + 2 条附加属性 | 5 件 |
| 传奇 | 橙色 | 固定基础属性 + 独特效果 | 3 件 |

首版约 20 件装备即可。可通过少量数值差异和固定词缀覆盖不同部位，不必为每种品质、每个部位制作大量独立角色动画资源。装备外观变化不是 MVP 的必要条件；优先通过角色 Sprite、武器图标和装备图标体现差异。

## 8.4 装备属性规则

- 基础属性以固定数值为主，避免玩家难以判断装备价值。
- 附加属性从受控词缀池中选择。
- 同一件装备不得生成互相矛盾的词缀。
- 暴击率、冷却缩减等百分比属性必须设上限。
- 传奇装备效果应有明确触发条件和冷却限制，避免无限触发或无上限叠加。
- 角色面板应展示装备带来的最终属性变化。

以下为首版建议配置，可根据实际掉落和战斗难度调整数值。

| 装备名称 | 部位 | 品质 | 主要效果 / 特殊词缀 |
|---|---|---|---|

## 8.6 掉落规则

建议首轮测试的掉落基准：

- 普通怪：有较低概率掉落普通 / 魔法装备；不保证每只怪掉落装备。
- 精英怪：必定掉落金币或基础奖励，并有较高概率掉落魔法 / 稀有装备。
- Boss：必定掉落一件至少稀有品质装备；首通额外奖励固定传奇物品或传奇物品保底机会。
- 传奇装备不能由普通怪高频掉落，避免稀有度失去意义。
- 玩家已拥有的装备仍可以重复掉落，但重复物品可出售换取金币；MVP 不增加分解或合成系统。

**参考概率（仅供首轮测试）：**

| 来源 | 普通 / 魔法装备 | 稀有装备 | 传奇装备 |
|---|---:|---:|---:|
| 普通怪单次击杀 | 约 3% | 约 0.5% | 不掉落 |
| 精英怪 | 约 50% | 约 25% | 约 2% |
| Boss | 不适用 | 必定至少 1 件 | 首通保底 1 件指定传奇或等价奖励 |

概率需要以单局实际掉落体验验证，不应只根据单次击杀概率判断。首局如果玩家没有得到任何有意义的装备，应通过精英奖励或关卡保底机制保证成长体验。

## 8.7 金币用途

MVP 金币仅用于关卡结束后的基础补给或商人购买（如首版没有商人，则金币只作为收集统计，不应设计没有用途的复杂经济）。建议首版仅设置一个神社商人或关卡结算补给选项：购买少量恢复道具和基础装备。若时间有限，可先不做商人，明确金币暂时只作为未来系统预留，不在 MVP 中提供无意义的强制收集。

# 9. 妖魂系统设计

## 9.1 系统定位

妖魂是《妖刀武士》的核心特色系统。它们并非普通装备的替代品，而是来自妖怪的力量结晶。妖魂提供少量基础属性，并带来能够感知到的技能或战斗效果改变。

与装备相比：

- 装备主要改变角色基础数值。
- 妖魂主要改变战斗方式或技能表现。
- 装备更换频率可以相对较高。
- 妖魂数量较少、效果更有辨识度，鼓励玩家围绕特定玩法构筑 Build。

## 9.2 妖魂槽位

- 玩家拥有 3 个妖魂槽位。
- 角色达到 2、5、8 级时分别解锁一个槽位；如首轮节奏需要，也可直接开放全部槽位以降低教学成本。
- 同一种妖魂最多装备 1 个，避免重复叠加同一效果。
- 妖魂可随时在非战斗状态下更换；战斗中不允许更换。
- 妖魂装备后立即生效，卸下后立即失效。
- MVP 不设置妖魂耐久、消耗、销毁或升级。

## 9.3 首版妖魂清单

| 妖魂 | 来源怪物 / 主题 | 基础效果 | 特殊效果 |
|---|---|---|---|
| 酒吞童子之魂 | 赤鬼 / 鬼族 | 攻击力 +5% | W 旋风斩伤害提高 10% |
| 雪女之魂 | 冰霜怨灵主题（后续区域） | 冰霜伤害 +5%（MVP 可表现为伤害加成） | Q 居合斩命中后使普通怪移动速度降低 20%，持续 2 秒；Boss 效果减半或不生效 |
| 天狗之魂 | 山灵 / 风妖主题 | 移动速度 +5% | E 影步距离提高 15% |
| 九尾狐之魂 | 幻妖主题 | 暴击率 +3% | R 鬼神斩暴击伤害额外提高 20% |
| 鬼蜘蛛之魂 | 蜘蛛妖主题 | 攻击速度 +5% | 普通攻击有 10% 概率附加 3 秒持续伤害；同一目标重复触发只刷新持续时间 |
| 镰鼬之魂 | 风刃妖主题 | 技能冷却缩减 +3% | Q 居合斩冷却额外缩短 0.5 秒 |

说明：MVP 的地图内容不一定包含全部六种妖怪。雪女、九尾狐、鬼蜘蛛、镰鼬可以作为后续区域妖魂，通过首版奖励、隐藏容器或暂时封存的图鉴条目提前展示，但不应为凑齐列表而在首张地图堆入不符合场景的怪物。

## 9.4 妖魂获取方式

- 与妖魂主题对应的精英怪和 Boss 有较高概率掉落。
- 普通怪仅有极低概率掉落低阶妖魂，若 MVP 不区分妖魂品质，则普通怪可以不掉落妖魂。
- 首次击败赤月鬼将必定获得酒吞童子之魂或与剧情对应的固定妖魂奖励。
- 隐藏区域可设置固定妖魂奖励，作为探索回报。

## 9.5 妖魂与技能联动约束

- 妖魂效果必须有清楚的触发条件。
- 同一效果不得重复叠加产生无限循环。
- 控制效果对 Boss 需要有独立限制，例如减速时间缩短或完全免疫硬控。
- 妖魂提供的数值加成应低于同阶段装备组合的总属性影响，避免妖魂成为唯一正确选择。
- 玩家应能通过装备说明预先了解特殊效果，而不是装备后才发现隐藏规则。

## 9.6 妖魂图鉴

MVP 可提供简单图鉴，显示妖魂名称、来源、已发现 / 未发现状态和效果说明。未发现妖魂只显示轮廓与简短传闻，不展示完整掉落概率。图鉴用于强化收集目标，不要求复杂成就系统。

# 10. 怪物设计

## 10.1 怪物设计原则

- 每种怪物应有一个容易识别的攻击方式。
- 玩家应能从动作、地面预警或声音判断危险。
- 怪物不应只靠提高生命值和伤害制造难度。
- 普通怪负责形成战斗节奏，精英怪负责测试玩家技能使用，Boss 负责综合考验移动、输出和危险识别。
- MVP 怪物数量保持克制，确保每种敌人都能被玩家理解。

## 10.2 普通怪物

### A. 赤鬼

| 项目 | 设计 |
|---|---|
| 角色定位 | 近战基础敌人 |
| 外观 | 小型红色鬼族，角短、身形结实，手持钝器或短斧 |
| 行为 | 发现玩家后直接追击，接近后进行单次挥击 |
| 攻击预警 | 攻击前有明显抬手动作 |
| 弱点 | 移动速度一般，攻击后有短暂间隔 |
| 掉落 | 金币、基础装备；极低概率掉落酒吞童子之魂碎片（如采用碎片机制） |
| 设计目的 | 教学玩家主动接近目标、判断攻击距离并进行普通攻击 |

### B. 骸骨武士

| 项目 | 设计 |
|---|---|
| 角色定位 | 近战进阶敌人 |
| 外观 | 破损铠甲包裹的骸骨武士，使用旧太刀 |
| 行为 | 缓慢接近，发动前方扇形斩击 |
| 攻击预警 | 刀举过肩，地面短暂出现攻击方向提示 |
| 弱点 | 攻击前摇较长，攻击后有明显空档 |
| 掉落 | 金币、普通 / 魔法装备 |
| 设计目的 | 教学玩家观察方向性攻击并移动躲避 |

### C. 怨灵

| 项目 | 设计 |
|---|---|
| 角色定位 | 远程干扰敌人 |
| 外观 | 半透明蓝灰色灵体，悬浮移动，面部轮廓模糊 |
| 行为 | 与玩家保持距离，发射缓慢灵体弹丸 |
| 攻击预警 | 发射前有聚光和短暂蓄力 |
| 弱点 | 生命值较低，移动速度慢；被近身后不擅长应对 |
| 掉落 | 金币、少量魔法装备 |
| 设计目的 | 迫使玩家调整站位，优先处理远程威胁 |

## 10.3 精英怪：鬼将

| 项目 | 设计 |
|---|---|
| 角色定位 | 区域精英、首次综合战斗考验 |
| 外观 | 身穿残破武士铠甲、戴鬼面，体型明显大于普通武士 |
| 技能一 | 重斩：前方扇形攻击，前摇明显 |
| 技能二 | 冲锋：短距离直线冲撞，路径有预警 |
| 技能三 | 召唤：生命值低于 50% 时召唤 1–2 只赤鬼（MVP 可选） |
| 战斗特点 | 攻击伤害高于普通怪，但攻击间隔足够玩家移动躲避 |
| 掉落 | 金币、较高概率魔法 / 稀有装备 |
| 设计目的 | 检验玩家是否会使用 E 躲避并在攻击间隔输出 |

## 10.4 Boss：赤月鬼将

<details>
<summary>Boss 设计完整说明</summary>

**背景：** 赤月鬼将原是守护枫隐神社的武士。封印节点破损后，他为了阻止怨灵进入村庄，与黄泉之力达成交易，最终变成失去理智的妖鬼。它仍保留守门人的执念，因此持续阻止所有人进入神社深处。

**外观：** 高大的武士鬼，穿着残破深色铠甲，头盔两侧有弯角，刀刃带暗红色光纹。造型应有武士身份特征，不应只是普通大型恶魔。

**战斗阶段：**

- 第一阶段（100%–60% 生命）：使用普通挥刀和地面重击，帮助玩家熟悉 Boss 攻击节奏。
- 第二阶段（60%–0% 生命）：攻击速度略微提高，增加冲锋和连续挥刀；攻击预警仍必须清楚。

**攻击动作：**

1. **横斩：** 前方扇形攻击，伤害中等，前摇明显。玩家可以通过移动离开扇形范围。
2. **地面重击：** Boss 高举武器后砸向地面，生成圆形范围危险区。玩家需要在攻击落地前离开范围，可使用 E 影步规避。
3. **冲锋：** Boss 短暂蓄力后沿直线冲向玩家起始位置。玩家可以横向移动躲避；冲锋结束后 Boss 有短暂恢复时间。
4. **鬼火爆发（第二阶段）：** 在场地内生成少量延迟爆炸区域。危险区域必须在爆炸前明显显示。

**战斗体验要求：**

- Boss 不应连续使用无法躲避的技能。
- 至少有一个明确输出窗口。
- 玩家合理使用 E 应能躲避主要危险攻击，但不能依赖持续无敌无伤通过整场战斗。
- Boss 攻击不应追踪玩家到最后一刻，避免玩家无法判断安全位置。
- Boss 生命值和伤害应允许一个正常成长的玩家在约 1.5–3 分钟内完成战斗。

**奖励：** 第一枚封印楔、剧情记录、经验、金币、至少一件稀有品质装备，以及首通固定妖魂奖励。

</details>

# 11. 关卡与地图设计

## 11.1 MVP 场景：枫隐村与隐月道场

### 场景定位

枫隐村由安全据点“隐月道场”和外围战斗区域组成。道场承担经营、补给、装备整理和出征准备；村道、竹林、神社承担探索、战斗、资源收集和 Boss 挑战。玩家通过往返两类场景理解经营与战斗的关系。

### 场景风格

- 采用 2D 正交俯视构图，所有地面、建筑、树木和角色遵循统一的俯视透视规则。
- 秋季山村，枫叶、石阶、木屋、纸灯笼和荒废神社构成主要视觉元素。
- 隐月道场是玩家的安全经营空间，具有主屋、刀匠铺、物资屋、神龛和训练场等固定设施点。
- 天色接近黄昏，局部有薄雾和鬼火。
- 色彩以灰褐、暗红、枯黄和冷蓝为主。
- 神社地下空间比村庄更压抑，出现石壁、封印纹样和暗红色裂隙。
- 整体保持可读性，地面、障碍物、可通行区域和战斗危险区必须容易区分。

## 11.2 地图区域

| 区域 | 内容 | 敌人 | 主要目标 |
|---|---|---|---|
| A. 隐月道场 | 安全据点、设施经营、补给和整备 | 无 | 学习交互、修复设施、准备出征 |
| B. 村口石桥 | 起始战斗区域、第一批敌人 | 赤鬼 | 学习移动、攻击和拾取 |
| C. 枫叶村道 | 木屋与岔路，形成第一次小规模遭遇 | 赤鬼、骸骨武士 | 学习使用 Q 与 W |
| D. 废弃竹林 | 视线受限、远程敌人和精英战 | 怨灵、骸骨武士、鬼将 | 学习走位与 E 闪避，并收集木材 |
| E. 神社前庭 | 机关与敌人组合，通往地下入口 | 三类普通怪 | 找到封印纹样并打开入口 |
| F. 地下神社 | 最终探索区、封印壁画和首领战 | 赤月鬼将 | 击败 Boss、获得封印楔 |

## 11.3 关卡流程

1. **抵达村口：** 主角发现道路被破坏，听到远处鬼火声。玩家获得移动和设施交互提示。
3. **清理村道：** 击败赤鬼，认识普通攻击和 Q 居合斩。
4. **穿越村落：** 遇到骸骨武士和怨灵，学习范围攻击与走位。
5. **调查竹林：** 发现神社封印碎片或记录，击败精英鬼将。
6. **进入神社前庭：** 击败守卫敌人，触发封印机关，打开地下入口。
7. **地下神社：** 通过短探索段，阅读壁画，了解七处封印节点。
8. **首领战：** 击败赤月鬼将。
9. **返回据点：** 获得封印楔，暂时稳定节点，获救村民出现。玩家返回隐月道场，解锁设施修复与下一阶段经营目标，并发现新的线索。

## 11.4 关卡目标与支线

**主线目标：**

- 修复隐月道场的基础设施并完成首次出征准备。
- 找到封印线索。
- 打开地下神社入口。
- 击败赤月鬼将。
- 取得第一枚封印楔。

**可选探索目标：**

- 找到 2 处村民遗留物，了解失踪事件。
- 发现 1 处隐藏供奉点，获得固定补给或装备。
- 找到神社壁画，解锁世界观图鉴条目。

支线目标只提供额外经验、金币或物品，不应成为通关强制条件。

## 11.5 地图设计约束

- MVP 使用固定地图，不要求随机生成。
- 玩家应能清楚辨别主路线与可选探索路线。
- 不设置容易造成长时间迷路的复杂迷宫。
- 单次从入口到 Boss 的正常探索时间建议为 8–12 分钟；完整首轮体验包含教学和结算建议为 10–15 分钟。
- 关键道路不得被随机掉落物、敌人尸体或特效遮挡。
- Boss 场地应相对开阔，保证玩家能看见攻击预警并有移动空间。

## 11.6 后续区域方向（非 MVP）

为了保持世界观扩展的一致性，后续区域可以按以下方向规划，但不纳入首版验收：

| 区域 | 主题 | 潜在妖怪 / 首领 | 故事方向 |
|---|---|---|---|
| 竹影山 | 迷雾竹林与山道 | 天狗、镰鼬 | 山中修行者失踪，风妖守护古老道路 |
| 鸦鸣城 | 被妖魔占领的城池 | 武士怨灵、怨将 | 忠臣仍在守卫一座已经灭亡的城 |
| 白骨原 | 古战场 | 骸骨军、怨将 | 战争中积累的集体执念形成妖灾 |
| 雪葬寺 | 冰雪古寺 | 雪女 | 一段未能兑现的约定让亡魂无法离去 |
| 鬼哭峡 | 黄泉裂隙 | 牛鬼、鬼蜘蛛 | 人间封印开始出现大规模崩坏 |
| 黄泉国 | 生死边界 | 诸多原创黄泉妖物 | 揭开月影家与黄泉之界的最终真相 |

# 12. 游戏界面与信息设计

## 12.1 主 HUD

| 区域 | 内容 | 要求 |
|---|---|---|
| 左上 | 角色头像、等级、生命值、经验值 | 生命值变化清晰；升级时有明显反馈 |
| 右上 | 小地图、区域名称、当前任务 | 显示已探索区域、玩家位置和目标方向 |
| 中央 | 游戏场景、敌人血条、交互提示、伤害数字 | 不长期遮挡角色和危险预警 |
| 底部中央 | 普攻提示、Q/W/E/R 技能栏 | 冷却状态和快捷键清晰可读 |
| 底部侧边 | 背包、角色、技能、任务、据点入口 | 图标有悬停说明和快捷键提示 |

## 12.2 角色面板

必须展示：

- 主角当前等级和经验进度；
- 最大生命值、攻击力、防御力；
- 暴击率、暴击伤害、攻击速度、移动速度、冷却缩减；
- 六个装备槽；
- 三个妖魂槽；
- 当前属性与装备变化后的属性对比。

属性对比规则：装备对比时，增加属性使用正向颜色，降低属性使用负向颜色；特殊效果必须显示文字描述，不能只用颜色表达。

## 12.3 背包面板

- 使用网格展示物品。
- 装备、妖魂、消耗品分类展示。
- 装备图标使用品质颜色边框。
- 悬停或选中时显示名称、品质、部位、属性、特殊效果和来源信息（若已知）。
- 装备可执行穿戴、卸下、对比和出售（如 MVP 设置商人）。
- 背包容量建议为 30 格；金币不占背包格子。
- 背包满时给出明确提示，不能静默丢弃物品。

## 12.4 技能面板

- 展示 Q/W/E/R 技能图标、技能名称、当前等级和效果。
- 显示强化前后变化。
- 可用技能点数量清晰展示。
- 未达到解锁等级时显示解锁条件。
- 已选择的强化方向不可再次选择另一个方向，除非后续版本加入重置功能。

## 12.5 任务与提示

- 屏幕任务提示只展示当前主线目标，不在画面中持续展示长篇剧情。
- 可选目标可在任务面板查看。
- 重要机关、可拾取物和可阅读记录应通过视觉提示与鼠标悬停说明识别。
- 教学提示采用短句，一次只解释一个新操作；玩家完成相应操作后不再重复显示。

## 12.6 据点经营界面

- 据点以完整 2D 俯视场景呈现，玩家可在场景内自由移动。
- 可交互设施使用轻量标识或靠近提示，不应持续显示大面积指引。
- 与设施交互后打开对应管理面板，显示设施等级、功能、升级材料和升级结果。
- 顶部或侧边常驻显示金币、木材、铁矿和妖魂碎片数量。
- 出征入口显示区域名称、推荐等级、主要奖励和危险提示。
- 据点界面与战斗 HUD 分开，避免经营信息遮挡战斗画面。

## 12.7 2D 角色与 Sprite Sheet 动画规范

### 12.7.1 动画资源原则

- 所有可动角色和怪物均使用 2D Sprite Sheet，不使用实时 3D 模型骨骼动画。
- Sprite Sheet 按角色、动作和朝向组织；同一动作的帧尺寸、锚点和角色比例保持一致。
- 俯视角角色至少需要上、下、左、右四个方向的基础动作；若美术资源允许，斜向移动可复用最近主方向动画。
- 角色在场景中的排序以脚底 / 地面接触点为基准，避免前后遮挡错误。
- 动画帧率以动作观感为准，普通移动建议 6–10 FPS，攻击与受击建议 8–12 FPS，最终以实际资源测试为准。

### 12.7.2 MVP 必需动作

| 对象 | 必需动画 | 说明 |
|---|---|---|
| 玩家武士 | Idle、Walk、Attack、Skill_Q、Skill_W、Dodge、Skill_R、Hit、Death | 至少支持四方向；技能动作应能辨识 |
| 赤鬼 | Idle、Walk、Attack、Hit、Death | 攻击前摇必须清楚 |
| 骸骨武士 | Idle、Walk、Attack、Hit、Death | 体现挥刀动作 |
| 怨灵 | Idle / Float、Move、Cast、Hit、Death | 悬浮移动可使用循环帧 |
| 精英鬼将 | Idle、Walk、Attack、Charge、Hit、Death | 与普通敌人有明显体型和动作差异 |
| Boss 赤月鬼将 | Idle、Walk、Slash、Slam、Charge、Skill、Hit、Death | 第二阶段可通过更换动画或叠加特效表现 |

### 12.7.3 Sprite Sheet 交付要求

- 每个动作单独提供图集或使用统一图集中的独立动画区域。
- 提供帧数、帧宽高、行列布局、播放帧率、循环方式和动作事件帧说明。
- 动作事件帧需标注攻击生效帧、位移起止帧、受击帧和技能特效触发帧。
- 所有帧使用透明背景，角色脚底锚点统一。
- Sprite Sheet 不得出现帧间角色漂移、尺寸跳变、边缘裁切或背景色块。
- 角色与怪物的碰撞体以独立逻辑尺寸定义，不直接等同于整张 Sprite 的透明边界。

## 12.8 视觉与音效反馈

| 事件 | 视觉反馈 | 音效反馈 |
|---|---|---|
| 普通攻击命中 | 短暂刀光、受击动作、伤害数字 | 清脆刀击声 |
| 暴击 | 更明显的伤害数字和短促特效 | 更强的命中音 |
| 玩家受伤 | 角色受击、生命条减少 | 受击音 |
| 技能释放 | 技能专属动作与效果 | 技能专属音效 |
| 技能冷却完成 | 技能图标恢复可用状态 | 可选轻提示音，不应频繁打扰 |
| 装备掉落 | 地面掉落精灵或图标、品质颜色 | 掉落提示音，品质越高反馈越明显 |
| 妖魂掉落 | 独特灵体光效和图标 | 与普通装备区分的声音 |
| 升级 | 角色周围光效、等级提示 | 升级音效 |
| Boss 进入战斗 | Boss 名称和生命条出现 | 专属登场音效 |
| Boss 被击败 | 倒地 / 消散演出、奖励展示 | 胜利音效 |

# 13. 物品、补给与经济边界

## 13.1 消耗品（MVP 可选）

为避免加入复杂资源系统，MVP 最多提供一种基础恢复道具：

| 道具 | 效果 | 使用限制 |
|---|---|---|
| 伤药 | 恢复最大生命值的 35% | 建议每局最多携带 3 瓶；使用后有短暂动作或公共冷却 |

若实现消耗品会明显扩大背包和商店工作量，可在首版先不提供。Boss 难度应在不依赖伤药的情况下可通过操作完成。

## 13.2 金币

金币可由怪物和关卡奖励获得。MVP 中金币必须有清晰用途，否则不应过度强调其掉落。可选用途为购买伤药和少量基础装备。首版不加入装备强化、词缀洗练或抽奖消耗。

## 13.3 经济原则

- 不设置必须反复刷取才能继续主线的硬性门槛。
- 首次通关所需装备可通过关卡固定奖励和正常掉落获得。
- 不将关键剧情道具放入低概率随机掉落池。
- 不通过故意压低掉率迫使玩家重复挑战。

# 14. 存档与进度规则（产品要求）

本节只规定玩家看到的进度保留规则，不规定具体保存方式。

- 玩家重新进入游戏时，应能够继续之前已保存的角色进度。
- 已获得的装备、妖魂、角色等级、技能强化和图鉴发现记录应保留。
- 关卡内未完成的临时战斗状态不要求保存；重新进入关卡时从关卡起点开始。
- 关卡完成状态应被记录，玩家可以再次挑战已完成关卡。
- 再次挑战时，已获得的剧情关键物品不应重复导致剧情状态冲突；重复奖励可转化为普通奖励。
- 玩家主动选择重新开始游戏时，应明确提示将重置哪些内容，并要求二次确认。

# 15. 教学与新手体验

## 15.1 教学目标

玩家在不阅读长篇说明的情况下，能够理解：

1. 使用 方向键可以移动。
2. 主动移动接近怪物后，可以使用普通攻击和技能。
3. Q/W/E/R 分别承担突进、范围输出、闪避和大招功能。
4. 怪物会掉落装备，装备需要进入背包后主动穿戴。
5. 妖魂可以装备在专属槽位并改变角色能力。
6. Boss 的危险攻击有预警，需要移动躲避。

## 15.2 教学节奏

| 阶段 | 教学内容 | 触发条件 |
|---|---|---|
| 据点 | 移动与设施交互 | 玩家首次进入隐月道场 |
| 第一只赤鬼 | 普通攻击与主动接近 | 玩家进入敌人警戒范围 |
| 第一批多怪 | 使用 W 处理群体敌人 | 玩家附近同时出现多只怪物 |
| 竹林攻击 | 使用 E 躲避攻击 | 怪物首次发动明显范围 / 方向攻击 |
| 首次掉落 | 拾取并查看装备 | 第一次装备掉落 |
| 首次设施修复 | 使用资源修复设施 | 第一次修复设施时 |
| 妖魂奖励 | 装备妖魂 | 第一次获得妖魂 |
| Boss 战 | 观察地面危险区域并躲避 | Boss 战前简短提示 |

教学提示可以跳过或关闭；关闭后不得反复弹出。玩家可在帮助页面重新查看基础操作。

# 16. MVP 范围与内容清单

## 16.1 MVP 必须交付

| 模块 | MVP 内容 | 验收重点 |
|---|---|---|
| 角色 | 1 名武士主角 | 可移动、攻击、受击、倒下和升级 |
| 普攻 | 1 套基础刀术 | 玩家主动接近敌人后可攻击，命中反馈正确 |
| 主动技能 | Q/W/E/R 共 4 个 | 具备不同用途、冷却与清晰反馈 |
| 场景 | 隐月道场 + 枫隐村 + 地下神社 | 据点可经营，战斗地图有主线、探索区域和 Boss 场地 |
| 普通怪 | 赤鬼、骸骨武士、怨灵 | 攻击行为有差异 |
| 精英怪 | 鬼将 | 有至少两种可识别攻击 |
| Boss | 赤月鬼将 | 至少两个阶段 / 明显变化，三种以上攻击动作 |
| 装备 | 6 个部位、约 20 件装备 | 有品质、属性、穿戴和掉落规则 |
| 妖魂 | 3 个初始可用，设计 6 种总内容 | 可拾取、装备、卸下并生效 |
| 等级 | 1–10 级 | 经验、升级、属性成长、技能点 |
| 背包 | 物品展示、分类、穿戴 | 满包提示、属性对比正确 |
| 经营 | 至少 3 个可交互设施、资源收集和设施升级 | 玩家能完成一次修复和一次升级 |
| 教学 | 移动、攻击、技能、掉落、经营、Boss | 玩家无需外部说明可完成基础流程 |
| 结算 | 通关与失败结算 | 奖励、用时和继续 / 重玩入口清楚 |
| 存档 | 角色和关卡进度保留 | 重新进入后数据一致 |

## 16.2 MVP 可延期

- 六种妖魂全部在首张地图中掉落；
- 完整商人和金币消费循环；
- 伤药道具；
- 装备出售；
- 完整妖魂图鉴；
- 隐藏区域和可选支线的丰富剧情；
- 装备穿戴后的角色外观变化；
- 复杂的剧情动画和配音。

延期项不得影响核心循环的完整性。

# 17. MVP 验收标准

## 17.1 核心流程验收

以下流程必须能够从头到尾完成：

1. 玩家进入游戏并抵达隐月道场。
2. 玩家能够与设施交互，查看资源并完成至少一次设施修复或升级。
3. 玩家在据点完成装备、妖魂和补给整备，并选择枫隐村出征。
4. 玩家使用方向键移动，角色能够在 2D 地图中正确移动并被障碍物阻挡。
5. 玩家主动接近赤鬼并使用普通攻击，攻击命中与动画反馈一致。
6. 玩家能够使用 Q/W/E/R，技能效果、冷却和伤害符合说明。
7. 玩家击败怪物后获得经验、金币或经营资源，达到阈值后升级。
8. 玩家能够拾取掉落装备并在背包中查看属性。
9. 玩家穿戴装备后，角色面板属性正确变化。
10. 玩家获得妖魂后，能够装备到槽位并观察到对应效果。
11. 玩家能够找到地下神社并触发 Boss 战。
12. 玩家能够观察 Boss 预警，使用移动或 E 技能躲避主要攻击。
13. 玩家击败 Boss，获得封印楔和关卡奖励。
14. 玩家返回据点，使用战斗所得资源进行设施升级或补给，并看到本次出征结算。

## 17.2 操作验收

- 方向键输入后，角色能正确移动，不出现无原因卡住或瞬移。
- 连续改变方向输入时，角色能及时响应，斜向移动速度不会异常增加。
- 玩家接近敌人后能在合理攻击距离发动攻击，不会贴入敌人碰撞体内部。
- 敌人死亡后，玩家不会继续对尸体执行攻击动作。
- 技能冷却期间重复输入不会造成技能误释放。
- 打开背包或暂停菜单时，游戏世界按规则暂停，角色不会因界面操作继续移动或受到攻击。
- 角色倒下后不能继续释放技能或攻击。

## 17.3 战斗验收

- 普通攻击、Q、W、E、R 的作用不同且玩家容易理解。
- 技能命中判定与视觉效果一致。
- 敌人攻击有可识别的前摇或范围预警。
- 玩家受到伤害时有明确反馈，生命值变化正确。
- Boss 至少有三种攻击行为，且不存在无法合理躲避的连续攻击组合。
- 玩家通过移动、技能时机和合理装备可以完成 Boss 战，不依赖随机获得传奇装备。

## 17.4 成长与掉落验收

- 经验值、等级、基础属性和技能点变化正确。
- 装备属性在穿戴、卸下和替换后正确增减。
- 妖魂基础属性与特殊效果在装备、卸下后正确生效或失效。
- 同类妖魂不能重复装备造成叠加漏洞。
- 掉落物不会落入无法到达的区域。
- 背包满时不会静默删除已有物品或新物品。
- 首次通关奖励有保底，不因随机数导致玩家无法获得剧情关键物品。

## 17.5 体验验收目标

以下为目标值而非硬性技术指标，需通过试玩观察：

| 指标 | 首轮目标 |
|---|---|
| 首次完整体验时长 | 10–15 分钟 |
| 玩家理解基础移动与攻击 | 无外部指导即可完成 |
| 玩家理解四技能用途 | 在教学与一次战斗后基本掌握 |
| 普通怪单次战斗 | 约 3–8 秒 |
| 精英怪战斗 | 约 15–30 秒 |
| Boss 战 | 约 1.5–3 分钟 |
| 成长反馈 | 至少获得一次升级、一次装备替换和一次妖魂装备体验 |
| 关卡完成率 | 内部测试玩家在熟悉规则后大多数能够完成 |

不能仅凭单一试玩者得出平衡结论。建议至少进行多轮内部试玩，记录失败原因、技能使用频率、Boss 战时长、装备替换率和玩家是否理解妖魂效果。

# 18. 风险与待验证事项

## 18.1 战斗是否足够有趣

**风险：** 四个技能数量有限，如果技能反馈和敌人差异不足，战斗可能变成重复点击。  
**验证方式：** 先制作小规模战斗体验，观察玩家是否会主动使用不同技能，以及是否能说清每个技能的用途。

## 18.2 俯视角键盘移动与碰撞手感

**风险：** 移动速度、碰撞边界、攻击距离和目标锁定若处理不好，会让玩家感觉角色操作不跟手。  
**验证方式：** 重点试玩连续键盘移动、方向移动目标、接近远程怪、目标死亡和障碍物附近移动等场景。

## 18.3 妖魂效果是否有实际差异

**风险：** 若妖魂只增加少量属性，玩家可能把它视为另一套装备数字。  
**验证方式：** 至少确保首版三种可用妖魂能明显改变一个技能或战斗行为，并让玩家能在短时间内感受到差异。

## 18.4 装备随机掉落的挫败感

**风险：** 随机掉落可能让玩家整局没有获得有价值的物品。  
**验证方式：** 首通通过固定奖励保证至少一次有意义的装备替换和一次妖魂获得；随机掉落只提供额外惊喜，不承担主线进度门槛。

## 18.5 内容规模超出独立开发承受范围

**风险：** 多区域、多怪物、多装备和大量 Sprite Sheet 动画会显著增加内容制作成本。  
**控制方式：** 首版严格限制为一个据点、一个主角、三种普通怪、一种精英、一名 Boss、一张主地图和一个地下神社区域。

## 18.6 数值尚未经过验证

**风险：** 本文所有数值都只是可测试起点，可能出现玩家输出过高、Boss 过硬、冷却过短或掉落过于稀少等问题。  
**控制方式：** 将战斗时长、玩家死亡率、Boss 技能命中率和装备升级幅度作为调整依据，不将初始数值固化为最终设计。

# 19. 版本规划建议

| 版本 | 目标 | 内容边界 |
|---|---|---|
| MVP 0.1 | 验证核心战斗 | 武士、基础移动、普攻、Q 技能、一种怪物、一件装备 |
| MVP 0.2 | 验证战斗循环 | 四技能、三种普通怪、基础掉落、等级成长 |
| MVP 0.3 | 验证角色 Build | 装备部位、背包、三种妖魂、技能强化 |
| MVP 0.4 | 验证关卡闭环 | 枫隐村、精英怪、Boss、封印楔和结算 |
| MVP 1.0 | 可公开试玩版本 | 教学、完整 UI、存档、音效、体验优化和验收问题修复 |

版本规划的重点是每个阶段都能被试玩和验证，而不是严格按日期交付。若基础战斗体验尚未成立，不应继续扩充大量装备和关卡内容。

# 20. 最终产品定义

《妖刀武士》的第一版不是一款内容庞大的开放世界游戏，也不是追求高难度精准格挡的硬核动作游戏。它是一款围绕**据点经营、资源收集、即时战斗、装备收集和妖魂构筑**展开的 2D 俯视角经营 + 动作 RPG。

首版成功的判断标准不是地图有多大、故事有多长或装备数量有多少，而是玩家能否在一段 10–15 分钟的体验中清楚感受到：

- 我能轻松控制武士在 2D 俯视地图中移动和攻击；
- 四个技能各有用途，战斗有节奏；
- 击败妖怪会得到值得期待的奖励；
- 更换装备和妖魂确实改变了角色能力；
- 我有明确的目标去探索神社、击败 Boss，并将战利品带回据点发展经营；
- 完成关卡后，我愿意再挑战一次，尝试不同装备和妖魂组合。

**MVP 的最终交付定义：玩家能够在隐月道场完成基础经营与出征准备，进入枫隐村完成探索、战斗、掉落和 Boss 挑战，再返回据点使用资源升级设施，体验“经营—出征—战斗—收集—成长—回归经营”的完整循环。**
